## ⚙️ What I build

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>📊 Google Sheets automation</h3>
      <p>Sync data, generate reports and trigger alerts without anyone opening the file. Cross-sheet and cross-file sync, scheduled digests, validation and alerting rules.</p>
      <h3>🌐 Apps Script web apps</h3>
      <p>Full applications served straight from a spreadsheet: forms, portals and dashboards with <code>doGet</code>/<code>doPost</code> back-ends and role-based access.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🕷️ Web scraping</h3>
      <p>Reliable extraction from sites that were never meant to be read by a machine. Price and stock monitoring, lead generation, scheduled crawls with retries.</p>
      <h3>📧 Gmail automation</h3>
      <p>Parsing, labelling, routing and templated replies for inboxes that get too much: field extraction, auto-labelling, smart replies.</p>
      <h3>🧩 Browser extensions &amp; userscripts</h3>
      <p>Manifest V3 extensions and Tampermonkey scripts that cut the clicks out of daily admin work: dashboards, form fillers, on-page capture.</p>
      <h3>📄 Docs, PDFs &amp; forms</h3>
      <p>Auto-generated proposals, contracts and invoices from structured data. Branded PDF generation and mail-merge at scale.</p>
